# 휴대폰 앱 변경 내역

## 0.5 (2026-11-02)
- 상단 상태바 글자·아이콘이 밝은 화면에서 흰색이라 안 보이던 문제 수정 — 화면 테마(라이트·다크)에 맞춰 색이 바뀜

## 0.4 (2026-11-02)
- 브레인 모드: 휴대폰 화면 정리 — 아래 업무 지시줄 한 줄(폴더·입력·첨부·AI·보내기), 팀 활동 단추 상단 바로, 진행 중인 업무 한 줄
- 브레인 모드: 회의 노트 주간회의·팀 회의별 묶음·한 줄 요약·노션 '쓰기', 중요 일정·브리핑 카드 강화
- 브레인 자료 Firebase 양방향 동기화(집·회사 컴퓨터)
- 상단 바·카드 아이콘 단추 동그랗게, 반응형 배치 수정

## 0.3 (2026-11-01)
- Android 16 에서 뒤로 가기 메뉴가 안 뜨던 문제 수정
- 서버가 15초 동안 응답 없으면 검은 화면 대신 서버 주소 창 표시
- debug 빌드에서 chrome://inspect 로 화면 점검 가능

## 0.2 (2026-10-30)
- 앱 안 업데이트: 열 때 새 버전 확인, 뒤로 가기 메뉴에서 '업데이트 확인'
- 뒤로 가기 메뉴: 서버 주소 바꾸기·새로고침
- 전체 글꼴 Pretendard GOV, 폴드 펼친 화면 배치 수정
