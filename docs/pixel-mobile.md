# 모바일 픽셀 사무실과 행동 에셋

모바일에서 픽셀 사무실은 22×24의 개방형 작업 공간이다. 개인 책상·의자 12석을 3열로 배치하고 회의실·탕비실·소파·장식은 그리지 않는다. 회의·휴식·대화 목적지는 유지한다. PC의 40×40 지도는 유지한다. 작은 지도는 초기 화면 너비 760px 이하에서 선택하므로, PC/모바일 지도를 바꾸려면 해당 너비에서 새로고침한다.

`web/pixel/mobile-layout.js`에서 좌표·책상·길 찾기 장애물을 함께 정의한다. 보이지 않는 벽·가구는 모바일 길 찾기에서 제외한다. `web/mobile-office.js`는 모바일에서 사각형 바닥의 두 축을 화면에 맞추고, 바닥을 좌우 너비에 맞춘다. 화면 높이에 따라 내려다보는 각도를 조정한다. 조작 버튼은 한 줄 트레이에 넣고 ‘화면 조작’ 버튼으로 열고 닫는다. 좁으면 트레이만 가로 스크롤하며, 닫혀 있을 때 키보드 포커스를 받지 않는다.

## 캐릭터

내장 imagegen 도구로 성인 9명과 사람 어린이 이든의 행동 시트를 새로 제작했다. 원본은 `web/pixel/v3/sources/`, 실행용 256×256 아틀라스와 초상은 `web/pixel/v3/characters/`·`portraits/`에 있다. 기존 v2 가구는 그대로 사용한다.

최종 프롬프트 구성:

- walk: 투명 배경, 8열×9행, 행마다 같은 직원의 정면 서기·정면 양발 걷기·측면 서기·측면 양발 걷기·후면 양발 걷기. 아홉 인물의 머리·복장·발 기준선 고정, 부드러운 팔 흔들기, 점프·텍스트·그림자 없음.
- actions: walk 시트를 참조한 투명 배경 8열×10행. 동일한 아홉 직원과 민트 상의의 네 살 사람 어린이. 정면·측면·후면 앉기, 정면 컵 들기·측면 마시기, 발표, 정면·후면 서기. 의자는 별도, 전신·동일 배율·발 기준선 고정.
- eden: 투명 배경 4열×4행. 검은 머리·민트 상의·네이비 반바지·흰 운동화의 동일한 네 살 남아. 정면·측면·후면·초상, 방향별 양발 걷기, 방향별 앉기, 컵 들기, 손 흔들기. 접지한 발과 반대편 팔 움직임, 텍스트·그리드·그림자 없음.

원본에서 투명 경계만 자르고 최근접 배율로 패킹한다. 재현 명령:

```sh
NODE_PATH=/path/to/node_modules node scripts/pixel/pack.cjs
```

`pngjs`가 필요하다. 프레임은 서기·양발 접지·발 모으기를 이동 거리 0.32 단위로 순환한다. 이동하지 않거나 순간 이동하면 서고, 방향 경계에 이력을 두어 정면·측면·후면이 깜빡이지 않는다. 시점 방향은 실제 카메라에서 구한다. 렌더 순서도 바닥 투영 높이로 정한다.

## 동물원 기능 이전

`life-pixel.js`는 공통 life.js 엔진에 동물원 대화·경리팀장 반응·주제별 대답·잡담을 공급하되 사람 호칭으로 바꾼다. 걷기·커피·휴식·업무 중단·방문객 기능은 기존 공통 엔진을 사용한다. 동물 외형과 배경 동물은 가져오지 않는다.

이든은 사람 픽셀 어린이로 표시한다. GPT를 엄마로 따라다니고, 엄마가 일하면 책상 옆에 앉는다. 엄마·팀원·조연에게 말 걸기, 답변, 혼잣말, 근처 대화 반응, 업무 중 반응과 말풍선 충돌 정리를 연결했다. 팀원 명단이나 업무 배정에는 포함하지 않는다.

`web/pixel/eden-dialogue.js`는 동물원 이든 대화 데이터·동작을 추출하여 생성한 파일이다. 동물원 내용이 바뀌면 다음 명령으로 동기화한다. 동물원 파일을 직접 수정하지 않는다.

```sh
python scripts/pixel/sync-eden.py
node tests/pixel-theme.cjs
```

## 후면 머리 흔들림 보정

걷기의 중간 프레임에 별도로 생성한 서기 이미지를 끼우면 뒷머리 모양·비율이 교대로 바뀐다. `sources/back.png`는 동일 인물의 후면 서기·양발 걷기를 같은 시트에서 제작한 대체 원본이다. 세 프레임의 배율을 서기 기준으로 공유하여 발을 내딛을 때 머리까지 확대·축소하지 않는다. 네 번째 열은 사용하지 않는다. 실제 몸 회전을 따라 방향을 선택하여 뒤돌 때 목표 방향으로 갑자기 튀지 않도록 한다.

후면 보정 프롬프트: 참조 시트와 동일한 아홉 직원 및 사람 이든, 투명 배경 4열×10행, 후면 서기·왼발 걷기·오른발 걷기·후면 앉기. 행마다 뒷머리 실루엣·머리 너비·목 위치·어깨 너비 고정, 팔다리만 움직임, 같은 키와 발 기준선, 점프·늘어남·뒤통수의 얼굴·텍스트·그림자 제외. 앉기 요청에 맞지 않은 네 번째 열은 채택하지 않았다.

브라우저에서 `previews/pixel-motion.html`을 열면 정면·측면·후면 동작을 함께 검수할 수 있다.
