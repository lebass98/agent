# 사진 기반 사무실 HTML 미리보기

서버를 실행한 뒤 `/office-photo-preview.html`을 연다. 현재 운영 사무실과 분리된 공간 스케치이며 `web/office-preview/preview.js`에서 배치를 조정한다.

- 사진 반영: 파란 금속 프레임 유리 파티션·중간 높이의 반투명 필름, 창가 블라인드, 밝은 우드 책상·회색 패브릭 칸막이, 유리 입구와 체크 테이블, 정수기·프린터·냉장고.
- 추정 요소: 전체 치수, 12석 배치, 유리 안쪽 개별실의 수·용도, 입구와 탕비실의 정확한 연결 관계. 실제 실측 도면이 아니다.
- 조작: 드래그 회전, 휠 확대, 우클릭 이동. 전체·업무·복도·입구·평면 시점과 사람·공간 이름·벽 표시, 낮·저녁 조명을 제공한다.
- 기존 로컬 three.js·OrbitControls와 한국인 캐릭터 에셋을 사용하며 외부 CDN을 호출하지 않는다. 사람 이미지 로딩은 HTTP 서버를 통해 확인한다.
- 사용자 제공 원본 사진 및 사진 속 사람의 신원은 저장소에 복사하지 않았다.
