# 사진 기반 사무실 HTML 미리보기

서버를 실행한 뒤 `/office-photo-preview.html`을 연다. 현재 운영 사무실과 분리된 공간 스케치이며 `web/office-preview/preview.js`에서 배치를 조정한다.

- 사진 반영: 파란 금속 프레임 유리 파티션·중간 높이의 반투명 필름, 창가 블라인드, 밝은 우드 책상·회색 패브릭 칸막이, 유리 입구와 체크 테이블, 정수기·프린터·냉장고.
- 추정 요소: 전체 치수, 세로 방향의 좌석 수(가로 3석 × 양면 × 3묶음으로 18석 배치), 탕비실 출입문과 베란다 폭·출입문 위치. 실제 실측 도면이 아니다.
- 사용자 확인 구조: 가로 3명씩 앉는 책상 배치, 회의실 2개, 입구 기준 왼쪽 모서리 탕비실, 창가 너머 베란다. 13종의 사람을 중복 없이 배치하고 나머지 좌석은 빈 의자로 표시한다.
- 조작: 드래그 회전, 휠 확대, 우클릭 이동. 전체·업무·복도·입구·베란다·평면 시점과 사람·공간 이름·벽 표시, 낮·저녁 조명을 제공한다.
- 기존 로컬 three.js·OrbitControls와 한국인 캐릭터 에셋을 사용하며 외부 CDN을 호출하지 않는다. 사람 이미지 로딩은 HTTP 서버를 통해 확인한다.
- 사용자 제공 원본 사진 및 사진 속 사람의 신원은 저장소에 복사하지 않았다.

## 실제 화면 적용

사용자 요청에 따라 구조를 넓은 40×40 평면으로 재구성해 실제 `/` 화면에 적용했다. 탕비실 문은 오른쪽, 앞줄 맨 오른쪽 한 자리는 비우며, 가로 3석의 두 줄이 마주 본다. 미리보기의 간단한 가구 대신 기존 가구와 장비 제작기를 그대로 재사용했다. 자세한 구성은 `office-layout.md`에 기록한다.
