# 공간 테마

사이트 진입 시 **사무실 / 동물원**을 고른다. 선택한 공간은 브라우저에 기억하며 다음 진입 시 해당 항목을 선택 상태로 보여 준다. 설정의 **공간 테마**에서 다시 고를 수 있다. 라이트·다크 화면 테마 및 일출·일몰 조명 설정과는 독립적이다.

- 사무실: 기존 공간과 사람 외형을 유지한다.
- 동물원: 넓은 섬(45×35) 동물원. 정문 광장·회의실(유리벽 회의 건물, 긴 테이블 의자 12·발표 화면·문 네 곳)·팀장 전망대·서식지 마을 5곳(대나무 숲·호수·정글·극지·사바나, 작업석 12)·카페·피크닉 잔디밭·호수 데크. 팀원은 동물 12종(`web/zoo-animals.js`) 중 하나로 일하며, 기본은 Claude 여우·GPT 판다·Gemini 수달이고 팀원 얼굴을 눌러 바꾼다(같은 동물은 한 명만, 이 브라우저에 저장). 기존 모델·역할·업무 배정·개인 대화 API를 그대로 쓴다.
- 동물원 식구(`web/zoo-life.js`, 에이전트 아님, 동물원에서만): 원장 코끼리(본부장 — 전망대 자리·회의실·카페·팀원 응원·명언, 발표 때는 회의실 뒤편에서 경청)·공작새(디자인팀장 — 계속 산책)·오리(경리팀장 — 가장 말이 많다. 곳곳을 돌며 간식·영수증·법인카드·전기세·업무 비용을 투덜거리고 팀원에게 지적, 원장님께 결재 독촉. 말은 묶음·앞말·끝말·품목·금액을 섞어 매번 다르게 만들고 최근 40마디는 반복하지 않는다). 배경 동물: 호수 오리·새·미어캣·펭귄·나비.
- 서로 대화(`web/zoo-life.js`, 동물원에서만): 누가 말하면 근처(동물원 식구 7.5m·팀원 5.5m)의 캐릭터가 주제(간식·돈·응원·명언·디자인·업무·날씨·인사)와 자기 말투(팀원·원장·디자인·경리)에 맞춰 대답하고 최대 3마디까지 주고받는다. 쉬는 둘이 가까우면 2~4마디 잡담, 공작새도 팀원에게 다가가 말을 건다. 업무 진행 대사·팀장 발표 중에는 끼어들지 않는다.
- 동물원 바깥(`web/zoo-forest.js`, 사무실의 '동네'에 해당): 언덕 지형·나무 6종 숲과 빈터·굽이치는 강과 다리·폭포와 연못·통나무집·캠핑장·전망대·먼 산·사슴·토끼·나룻배·물고기·열기구·새 떼. 확대하면 숨고 축소하면 솟아오르며, 카메라 도구 '숲' 버튼으로 본다. 밤에는 창·모닥불·등이 켜진다.
- 사무실은 NPC(본부장·디자인팀장, npcs.js)와 산책 강아지를 불러오지 않는다. 동물원은 위의 동물원 식구를 쓴다. 기존 파일과 이미지 원본은 보존한다.
- 동물원 작업석은 12석(에이전트 설정의 최대 팀원 수)이며, 팀원이 없는 마을 자리에는 빈 책상이 놓인다. 나무는 시야를 가리지 않게 섬 안에는 최소로 둔다.
- 다른 공간으로 바꾸면 화면을 다시 불러온다. 서버의 업무 결과는 재접속 스냅샷으로 복원하며, 업무·답변 진행 중 전환은 막는다. 미전송 업무 문구는 같은 탭에서 복원한다. 브라우저 메모리에만 있는 개인 대화 이력은 새로고침 시 초기화된다.

## 구조

- `web/space-theme.js`: 앱 초기화 전에 선택값을 읽고 진입 다이얼로그·설정 버튼·공간별 화면 문구를 제공한다. 유효한 공간 ID만 허용한다. `space` URL 매개변수는 해당 페이지의 공간을 지정한다.
- `web/space-theme.css`: 진입 선택 화면. 키보드·모바일·시스템 다크 모드를 지원한다.
- `web/zoo-theme.js`: 동물원 선택 시 `Decor`를 교체한다. `build`, `spots`, `deskSet`, `nav` 계약과 해 고도 계산은 기존 앱에 연결한다. 연못·책상·나무·계획 보드 등을 이동 장애물로 등록하며 섬 바깥은 격자에서 차단한다. 방석·벤치는 착석을 위해 통행 장애물에서 제외한다.
- `web/app.js`: 선택에 따라 사람 또는 동물 rig를 만들고, 기존 업무 이벤트·말풍선·이동·타이핑·회의 애니메이션을 적용한다. 발표 위치도 해당 공간의 좌표를 쓴다.
- 동물원에서는 `outside.js`의 실제 주소 주변 지도 기능을 초기화하지 않는다.
- `previews/zoo-3d.html`: 기존 독립 맛보기 원본. 실제 앱의 테마 선택 및 업무 기능은 루트 페이지에 있다.

동물은 구·원뿔·상자 등으로 만든 관절형 3D 모델이며 앞·옆·뒤 모두 입체다. 고급 털·스킨 애니메이션을 사용하지 않는다. 표정은 눈의 형태 변경으로 표현하고 UI 아바타는 동물 이모지를 사용한다. 이미지 생성 모델이나 외부 CDN은 사용하지 않는다.

## 검증

- `node tests/zoo-theme.cjs`: 48×38 평면·작업석 12·회의실 의자 12(벽·문 사이 경로 포함)·목적지 사이 2401개 경로·호수·분수·울타리 통행 금지·동물 배정(중복 없음)·사무실 Decor 유지.
- `node tests/zoo-animals.cjs`: 동물 12종·동물원 식구 2종 rig 계약·입체 범위·표정·재질 분리.
- `node tests/space-theme.cjs`: 선택값·재진입·저장소 차단·업무 중 전환 방지·미전송 문구 복원 검사.
- 기존 평면·휴식 취소·사람 외형 검사 및 pytest 120개 통과.
- 모의 서버 브라우저: 진입 선택, 사무실→동물원 전환, 완료 업무 스냅샷 복원, 팀 활동 3명 및 개인 대화 연결 확인. 실제 유료 모델 호출은 이 검증에 포함하지 않는다.
