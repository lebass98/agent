# 공간 테마

공간 테마는 **모양만 다르고 구조는 같다.** 동물원을 기준으로 정한 공통 규격(`web/theme-kit.js`)을 모든 테마가 따르며, 새 테마를 더해도 같은 뼈대를 쓴다.
라이트·다크 화면 테마 및 일출·일몰 조명 설정과는 독립적이다.

## 고르기

- 처음 진입할 때 한 번 고르기 창이 뜬다(테마 목록은 `ThemeKit.THEMES`). 고른 공간은 브라우저에 기억하며 다음 진입부터는 묻지 않는다(주소에 `space` 를 붙여 들어와도 묻지 않는다). 저장소가 막힌 브라우저(사생활 보호 창 등)에서는 기억할 수 없어 진입할 때마다 묻는다.
- 바꾸는 곳: 왼쪽 위 경로의 공간 단추(**워크스페이스 / 🏢 사무실 ▾**, `#spaceBtn`) · 설정 **공간 테마**.
- 다른 공간으로 바꾸면 화면을 다시 불러온다. 서버의 업무 결과는 재접속 스냅샷으로 복원하며, 업무·답변 진행 중 전환은 막는다. 미전송 업무 문구는 같은 탭에서 복원한다.

## 공통 규격 (`web/theme-kit.js`)

| 항목 | 규격 | 사무실 | 동물원 |
|---|---|---|---|
| 작업석 | 12 (0번 = 팀장, `exec` 구역) | 팀장실 팀장 책상 + 업무 공간 마주 보는 4줄 11석 | 팀장 전망대 + 서식지 마을 5곳 11석 |
| 회의 의자 / 커피 자리 | 12 / 12 | 회의실 1 긴 테이블 / 탕비실 | 유리벽 회의 건물 / 카페 둘레 |
| 방 7개(키·역할 공통) | lobby 입구 · pantry 간식·커피 · work 작업 공간 · exec 팀장 자리 · meeting 회의·발표 · lounge 쉼터 · balcony 바깥 쪽 휴식 | 현관 · 탕비실 · 업무 공간 · 팀장실 · 회의실 1 · 라운지 · 베란다 | 정문 광장 · 카페 · 서식지 마을 · 팀장 전망대 · 회의실 · 피크닉 잔디밭 · 호수 데크 |
| 발표·보고 자리 | `PRESENT_SPOT`(회의실 화면 옆) · `REPORT_SPOT`(팀장 책상 옆) | TV 옆 · 팀장실 | 발표 화면 옆 · 전망대 |
| 조연 3명(이름표, 에이전트 아님) | design 디자인팀장 · head 본부장 · duck 경리팀장 | 사람 3명(본부장 자리 = 팀장실 소파) | 공작새 · 코끼리(원장) · 오리 |
| 산책 손님 3명(이름표 없음) | 쉼터·창가·산책로를 오간다 | 방문객 3명(사람) | 치이카와 친구 3종 |
| 서로 대화 | 팀원(AI)·조연 모두 | 같음 | 같음 |
| 배경 생물 | 테마가 주는 함수(매 프레임) | 베란다 비둘기 | 호수 오리·새·미어캣·펭귄·나비 |
| 바깥 풍경 | 축소하면 솟아오름 + 카메라 도구의 바깥 단추(`.outside-zoom`) | `outside.js` '동네'(실제 주소 주변 OpenStreetMap 또는 가상 동네) | `zoo-forest.js` '숲' |
| 팀원 외형 | 테마별 외형 목록(같은 외형은 한 명만, 브라우저에 저장) | 사람 그림 13종(`character-looks.js`) | 동물 15종(`zoo-animals.js` 12 + `zoo-friends.js` 3) |

- 팀원 수가 작업석(12)보다 많으면 넘는 팀원은 3D 에는 없고 목록·보드에만 보인다(에이전트 설정의 최대 팀원 수도 12).
- `ThemeKit.check(Decor)` 가 규격(키·방·자리 수·조연 장소)을 검사한다. 노드 테스트가 세 테마 모두에 돌린다.

## 구조

- `web/theme-kit.js`: 규격(숫자·방 역할·조연 역할·Decor 계약 키)과 테마 목록. `space-theme.js` 보다 먼저 읽는다.
- `web/space-theme.js`: 앱 초기화 전에 선택값을 읽고 고르기 창·경로 단추·설정 단추를 만든다. 방 단추 이름은 테마 지도(`Decor.rooms`)의 이름 하나만 쓴다. 공간 이름이 들어가는 화면 문구(홈 메뉴·브랜드·제목)를 테마 정보로 채운다.
- 테마 지도(`Decor`): 사무실은 `web/decor.js`, 동물원은 `web/zoo-theme.js` 가 `Decor` 를 교체한다. 둘 다 같은 계약(`ThemeKit.DECOR_KEYS`: `SEATS`·`rooms`·`spots`·`spareDesks`·`navRects`·`nav`·`build`·`deskSet`·`theme`·`PRESENT_SPOT`·`REPORT_SPOT`·`COFFEE`·`LIFE`·`NPC` 등)을 내놓는다. `Decor.NPC` 는 조연 장소(본부장 자리·회의실 뒤편·산책 지점·경리팀장 순찰 지점·회의실 문 앞, 동물원은 말투용 구역 `zones` 도)다.
- `web/app.js`: 작업석 수는 `Decor.SEATS`. 팀원 외형은 한 곳의 어댑터(`LOOKS`: 고른 외형·표정 띠·3D 모델·아이콘·고르기 창·안내 문구)로 테마를 나눈다. 공간 이름 문구는 `SPACE.label`.
- `web/life.js`: 공통 조연 엔진. 조연 3명의 동작(돌아다니기·팀원 방문·응원·명언·발표 경청·결재 독촉·간식 잔소리), 서로 대화(근처에서 누가 말하면 주제·말투에 맞춰 최대 3마디, 쉬는 둘은 2~4마디 잡담 — 업무 진행 대사·발표 중에는 끼어들지 않는다), 손님 산책, 배경 생물을 움직인다. 팀원이 아니므로 `D.names`·`D.agents` 에 넣지 않는다(이름표 겹침 정리 때만 잠깐).
- `web/life-office.js` · `web/life-zoo.js`: 테마별 조연 '내용' — 모양(고정 `kind` 또는 사람 그림 후보 `looks`, 팀원과 겹치면 다른 모양으로), 말투 낱말(`{head}` 본부장님/원장님 · `{org}` 사무실/동물원), 공통 대사에 덧붙일 대사, 구역별 경리팀장 잔소리, 잡담, 배경 생물 함수. 등록 위치 `ThemeKit.life[테마]`.
- 바깥 풍경: 사무실 `outside.js`(동물원에서는 초기화하지 않는다), 동물원 `zoo-forest.js`(사무실에서는 아무것도 하지 않는다).
- `previews/zoo-3d.html`: 기존 독립 맛보기 원본.

### 새 테마 더하기

1. `theme-kit.js` 의 `THEMES` 에 한 줄(id·이름·아이콘·설명·브랜드·제목).
2. 테마 지도: `Decor` 계약을 채운다(작업석 12·회의 12·커피 12·방 7·`PRESENT_SPOT`·`REPORT_SPOT`·`NPC`). `ThemeKit.check` 가 빈 곳을 알려 준다.
3. `life-<테마>.js`: 조연 3·손님 3 모양과 말투, 배경 생물.
4. 팀원 외형: `app.js` 의 `LOOKS` 어댑터에 테마 분기 하나.

## 검증

- `node tests/office-layout.cjs`: 사무실 40×40 · 공통 규격 · 0번 팀장실 · 11석 마주 보는 두 줄 · 발표 자리 · 조연 장소 포함 전 구역 이동 경로.
- `node tests/zoo-theme.cjs`: 동물원 48×38 · 작업석 12 · 회의 12 · 2401개 이동 경로 · 공통 규격 · 조연 장소 통행 · 사무실 Decor 유지.
- `node tests/zoo-animals.cjs`: 동물 12종 · 조연 3종 rig 계약 · 입체 범위 · 표정 · 재질 분리.
- `node tests/zoo-friends.cjs`: 친구 3종 입체·관절 · 49개 산책 경로 · 동물원 손님 등록.
- `node tests/space-theme.cjs`: 선택값 · 처음 한 번만 묻기 · 저장소 차단 · 업무 중 전환 방지 · 미전송 문구 복원.

## 픽셀 스튜디오 (2026-10-17)

세 번째 공간 `pixel`은 Canvas 2D로 그리는 아이소메트릭 픽셀아트 사무실이다. `?space=pixel` 주소, 첫 공간 선택창, 왼쪽 위 공간 변경 버튼에서 선택한다. 화면 선택은 기존과 같이 브라우저에 기억한다.

- `web/pixel-theme.js`: 승인한 단순 도트 시안의 전용 PNG를 사용하는 Canvas 2D 렌더러. `web/pixel/v2/assets.js`와 `manifest.json`에 캐릭터 9명 × 16프레임, 얼굴 9개, Apple 스타일 컴퓨터를 포함한 가구 12종의 좌표와 경로를 기록한다. 모든 이미지는 로컬 파일이며 CDN·WebGL이 필요 없다. 추가 팀원에게는 기존 절차형 도트 외형을 제공한다.
- 확대·축소는 20% 단위로 즉시 전환하고, 픽셀 공간의 카메라 보간·관성을 끈다. 카메라의 투영 원점을 Canvas 2D의 2 CSS-pixel 격자에 맞춰 화면 이동 중 고정 가구가 서로 다른 픽셀 위상으로 흔들리지 않게 한다. 캔버스 CSS 크기도 정수 2배로 고정한다. 걷기 프레임 높이는 48, 착석은 40으로 맞추고 발 위치를 고정한다.
- 공통 `Decor` 지도는 사무실의 검증된 40×40 좌표·통행 경로를 공유하고 `build/deskSet/theme`만 픽셀용 상태 객체로 대체한다. 작업 12·회의 12·커피 12·공간 7·조연 3·손님 3 규격을 유지한다. Three.js 로컬 사본은 좌표·카메라 계산 및 공통 Agent 상태 계약에만 사용한다.
- `app.js`는 픽셀 테마에서 `PixelTheme.Renderer`와 `LOOKS` 픽셀 어댑터를 선택한다. 걷기·앉기·타이핑·차·앉아서 차·서서 발표의 7종 자세와 정면·측면·후면, 각 2프레임을 제공한다. 외형 선택창도 픽셀 얼굴을 보여 준다. 몸 클릭은 화면에 그린 캐릭터 경계로 판정하며, 이동 드래그는 클릭으로 처리하지 않는다.
- `web/life-pixel.js`: 기존 공통 조연 엔진에 픽셀 말투·전용 조연 외형 3명(디자인팀장·본부장·경리팀장)·손님 3명(방문객·택배 기사·인턴)을 등록한다. 루프 가든 비둘기 3마리가 배경 생물이다. 배경 움직임과 화면 깜빡임은 동작 줄이기 설정을 따른다.
- `web/pixel-theme.css`: 도트 캔버스·민트색 프레임·픽셀 얼굴·공간 선택 카드. 기존 사무실과 동물원 스타일은 유지한다.
- 픽셀 테마는 왼쪽/오른쪽 드래그와 한 손가락으로 화면 이동, 휠/두 손가락으로 확대한다. 회전은 고정 아이소메트릭 시점이다. 공간 탭과 방향 버튼·키보드 방향키는 공통 카메라 조작을 쓴다.
- 실제 주소 기반 3D 동네는 픽셀 테마에서 실행하지 않는다. 기존 사무실의 주소·동네 설정은 보존한다. 낮/밤은 기존 일출·일몰 설정으로 색조만 부드럽게 바뀌며 강한 바닥 반사는 없다.

검증: `node tests/pixel-theme.cjs` — 공통 규격·전 구역 이동 경로·9명 전용 144프레임 경계·가구 파일 존재·걷기 프레임 크기·홀수 화면 크기에서 카메라 격자·스냅 드리프트·Canvas 2D 전용·몸 클릭·숨긴 인물 제외·외형 해제·다른 테마 지도 보존. `node tests/space-theme.cjs`는 픽셀 선택·기억·주소 진입·업무 중 전환 방지도 확인한다.
