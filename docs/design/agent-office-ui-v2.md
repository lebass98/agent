# Agent Office UI 고도화 시안 v2

2026-10-14 · ImageGen 내장 도구로 제작한 디자인 검토용 이미지. 실제 구현 화면이나 완료된 3D 모델이 아니다.

- 중앙: 큰 사무실 뷰, 방 이동과 확대·회전 도구.
- 상단: 업무 제목과 계획 → 분석 → 개발 → 검수 진행 상태.
- 우측: 팀원별 현재 활동과 실시간 대화·기록.
- 하단: 단계별 업무 카드와 팀 지시 입력창.
- 시각 언어: 차콜 패널, 밝은 텍스트, 절제한 파란 포인트, 따뜻한 건축 조명.
- 전자제품: Apple 계열 기기 디자인을 시각 방향으로 반영. 제품 형상·로고·치수는 구현 시 별도 검증.
- 생성 이미지 속 모델명·대화·시간·진행률은 예시 데이터. 실제 앱에서는 team.toml 및 서버 이벤트를 사용한다.
- 정밀 3D 제작·Apple 기기 교체 요청은 진행 중이며 이 이미지로 완료된 것이 아니다.

## 생성 프롬프트 요약

한국어 멀티 에이전트 업무 앱의 고해상도 데스크톱 UI 한 장. 얇은 좌측 내비게이션, 큰 중앙 3D 사무실, 상단 업무 단계 진행 바, 우측 Claude/GPT/Gemini 활동과 대화 패널, 하단 업무 카드와 명령 입력창. 차콜·아이보리·차분한 파란색 UI와 따뜻한 원목·유리·야경 사무실. 시트의 캐릭터 의상·헤어 식별 요소와 Apple 기기 디자인을 반영. 기기 프레임 없는 앱 전체 화면.

## UI 구현 (2026-10-14)

`web/dashboard.css`와 `web/dashboard.js`에서 실제 UI로 적용했다. 기존 업무 리듀서·서버 이벤트와 연결하여 상단 단계 표시, 실제 하위 업무 종료 비율, 팀원별 상태, 활동 기록과 업무 카드가 갱신된다. 방 전환·확대·축소, 검색·결과 보고서 기능을 유지했다. 기본 테마는 다크이며 저장된 라이트/시스템 설정은 존중한다.

데스크톱과 390×844 모바일 브라우저에서 모의 업무 접수→4건 실행→검수→최종 보고서 흐름을 확인했다. 모바일 팀 패널 열기/닫기 및 하단 입력창·가로 업무 카드 표시를 확인했다. 브라우저 오류 0, pytest 36개 및 CLI 모의 실행 통과.

실제 구현 화면: `agent-office-ui-v2-implemented.png`. 생성 시안의 반실사 3D 공간은 아직 적용되지 않았다. 현재 중앙 뷰포트는 기존 절차형 사무실/캐릭터를 실시간 렌더링한다. 정밀 3D와 Apple 기기 모델 교체는 별도 진행 항목이다.
