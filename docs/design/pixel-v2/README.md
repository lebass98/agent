# 픽셀 스튜디오 v2

승인한 시안은 `concept.png`다. 큰 도트, 짧은 캐릭터 비율, 단순한 눈, 따뜻한 원목·아이보리와 청록·세이지 팔레트를 사용한다. 바닥에는 광택이나 빛반사를 넣지 않는다.

## 에셋

- 팀원: Claude(팀장), GPT(디자이너), Gemini(업무 지원)
- 조연: 디자인팀장, 본부장, 경리팀장
- 손님: 방문객, 택배 기사, 인턴
- 인물마다 정면·측면·뒷모습, 걷기 6프레임, 착석 3방향, 차 마시기 2방향, 발표, 얼굴을 포함한 16셀 전용 시트를 제작했다.
- 가구 12종: 작업 책상, 팀장 책상, 회의 테이블, 소파, 커피 카운터, 책장, 화분, 리셉션, 발표 화면, 원형 테이블, 의자, 스탠드. 컴퓨터는 실버 Apple 스타일이다.

런타임 파일은 `web/pixel/v2/characters`, `portraits`, `furniture`에 있고 좌표표는 `manifest.json`과 `assets.js`다. 생성 원본은 `web/pixel/v2/sources`에 보존한다. 원본을 표시하지 않고 도트 해상도로 추출한 파일만 화면에서 사용한다. 새로운 이름의 추가 팀원은 기본 도트 외형을 사용한다.

## 제작과 재추출

이미지는 내장 `image_gen` 도구로 생성했다(API/CLI 대체 경로 사용 안 함). 정확한 생성 프롬프트는 `prompts.json`에 기록했다. 시트에서 투명 영역의 경계를 찾아 nearest-neighbor로 축소하고 64×64 셀에 발 위치를 고정한다. 걷기 높이 48, 착석 높이 40, 얼굴 48×48이다. 생성 결과의 alpha를 유지하며 그림을 코드로 덧칠하지 않는다.

```sh
npm install --prefix /tmp/pixel-tools pngjs
NODE_PATH=/tmp/pixel-tools/node_modules node scripts/sprites/pixel-v2.cjs
node tests/pixel-theme.cjs
```

공통 지도와 길찾기(작업석 12, 회의석 12, 커피 자리 12, 방 7개)는 유지한다. 조연과 손님은 실제 AI 팀원에 추가하지 않는다. 외형 선택은 `agentOffice.pixel.appearance.*`로 다른 공간과 별도 저장한다.

## 확대·이동 안정화

휠·버튼·두 손가락 확대는 20% 단계다. 휠의 미세한 입력을 누적하고 짧은 간격의 중복 확대를 제한한다. 픽셀 테마의 카메라 보간·관성을 끄고, 카메라 이동을 화면 전체에 공통인 정수 도트 격자에 맞춘다. Canvas CSS 크기는 내부 해상도의 정확한 2배로 유지한다. 확대 단계가 바뀌는 순간의 한 번의 크기 변화는 픽셀 표현상 정상이며 연속 보간으로 인한 떨림을 피한다.

검증: 픽셀 규격·에셋 144프레임·걷기 높이·이동 경로·몸 클릭·카메라 스냅 및 드리프트, 공간 선택 회귀 검사, 사무실 평면 검사, 모의 CLI 전체 실행. 브라우저 모의 서버에서 착석 화면·방 확대·몸 클릭 대화를 확인한다.
