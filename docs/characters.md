# 캐릭터 명세 (사용자 제공 캐릭터 시트 기준)

사용자가 준 캐릭터 시트(정면·좌측면·우측면·후면 / 서있는·걷는·앉은 자세 / 표정)를 사무실에 옮길 때의 기준.
**이 문서가 이전 목업(후드티·헤드폰 등)보다 우선한다.**

## 그림 캐릭터(2.5D, 현재 기본) — Claude · GPT · Gemini
시트 그림의 퀄리티를 그대로 쓰기 위해, 시트에 있는 세 팀원은 3D 인형 대신 **그림을 카메라 쪽으로 세운 판(빌보드)** 으로 그린다.
- 원본: `docs/ref/character-sheet-v2.png`(포즈 시트), `character-sheet-v1.png`(이전 시트), `office-dark.png`(다크 모드 사무실 참고).
- 자르기: `python3 scripts/sprites/cut.py`(Pillow·numpy·scipy, macOS 14+). macOS Vision 피사체 분리(`scripts/sprites/vmask.swift`)로 배경을 지우고,
  인물마다 머리·몸통을 씨앗으로 이어진 픽셀을 따라 갈라 옆 사람과 겹친 신발 조각을 떼어 낸 뒤, 가장자리에 섞인 배경색을 뺀다(어두운 장면의 흰 테두리 방지).
  결과: `web/sprites/<이름>.png`(몸 13프레임 아틀라스, 1024×256) · `<이름>-faces.png`(표정 6칸) · `sprites.js`(좌표표, 직접 고치지 말 것).
  시트 칸 위치·배율은 cut.py 의 `PANELS`·`PPU`(서 있는 정면 225px = 키 1.75), 자동으로 안 떼어지는 조각은 `ERASE` 에 적는다.
  '다양한 행동 포즈' 칸은 허벅지에서 잘려 있고 흰 스티커 외곽선이 있어 쓰지 않는다.
- 런타임: `web/sprite-chars.js`(rig 계약을 따르고 뼈대는 비어 있음, `rig.sprite` 가 연출).
  - 방향: 캐릭터가 바라보는 쪽과 카메라 방위의 차이로 정면(<30°)·측면·후면(>150°), 경계 ±8° 이력. 측면 왼쪽은 오른쪽 그림의 거울상(서 있을 때만 시트의 좌측면).
    기본 시점에서 책상·회의 의자는 대각선(45°·135°)이라 늘 측면으로 보인다.
  - 걷기: 이동 거리 0.32 마다 '걷기 ↔ 서기' 프레임을 번갈아 보이고(왼쪽은 둘 다 거울상 — 소품 든 손이 바뀌지 않게) 위아래로 살짝 튄다.
  - 앉기·일어나기: '일어나는 중' 프레임을 0.25초(앉을 때)·0.35초(일어날 때, 그동안 이동을 멈춤 `hold()`) 거친다.
    앉은 그림에 의자가 있으므로 앉아 있는 동안 자리의 3D 의자(`Decor.chairNear`)를 숨긴다.
  - 판은 수직으로 세워 책상·칸막이와의 앞뒤 가림을 3D 그대로 맞추고, 위에서 내려다보며 납작해 보이는 만큼 키를 조금(최대 1.2배) 늘린다.
    알파 커버리지(MSAA)로 가장자리를 부드럽게, 발밑에는 둥근 그림자. 다크 테마에서는 살짝 따뜻하게 색을 낮춘다.
  - 표정: 얼굴이 그림에 있으므로 `setFace` 는 이름표·팀원 카드·활동 로그의 **표정 아바타**(표정 띠 CSS 배경, `style.css` `.face`)를 바꾼다.
- 시트에 없는 팀원(이름이 claude·gpt·gemini 가 아닌 경우)은 아래 3D 프리셋 캐릭터(`characters.js`)를 그대로 쓴다.
- 리얼 3D 로 바꾸려면: 시트를 바탕으로 한 GLB/VRM 모델(AI 이미지→3D 또는 VRoid)과 걷기·앉기·타이핑 애니메이션(Mixamo 등)이 필요하다.

## 3D 프리셋 캐릭터(시트에 없는 팀원용)
3D 로는 반실사 그림을 그대로 재현할 수 없으므로, 아래 식별 요소(머리 모양·옷 색·소품·표정)를 정확히 맞추는 데 집중한다.

## 현재 3D 제작 기준

- 1 단위=1m, +Y 위, +Z 정면, 원점은 발바닥. Claude 1.72m / GPT 1.78m / Gemini 1.68m(머리카락 포함). 참고 이미지에는 실측값이 없어 이 값은 제작 기준이다.
- Claude·GPT·Gemini는 `SpriteChars.build` 그림 캐릭터를 사용한다. `Characters.build`는 시트에 없는 팀원과 이전 크기 검수용이다. 도형 캐릭터는 요청한 정밀 모델이 아니다.
- 의자 좌판 상단 0.535m에 맞춰 캐릭터별 hipHeight로 착석 오프셋 계산.
- [3D 에셋 안내](assets-3d.md)를 참고한다.

## 공통
- 체형: 날씬한 성인 비율(머리는 친근하게 살짝 크게, 전체 키 ≲ 1.85 단위). 4방향에서 모두 자연스러워야 함(뒷머리·뒷모습 포함).
- 피부: 밝은 살구색. 얼굴은 캔버스 텍스처로 그려 표정을 바꾼다.
- 공통 소품: **네이비색 목걸이 줄(lanyard) + 흰색 사원증**(가슴 앞). 흰색 스니커즈.
- 앉은 자세: 회색 사무용 의자, 책상의 Studio Display를 보며 외장 키보드로 타이핑, 옆에 머그컵. 측면에서는 다리를 꼬기도 함.
- 걷는 자세: 한 팔을 자연스럽게 흔들고, 소품(태블릿·노트북·커피)은 다른 손에.

## 1. 여자 캐릭터 1 → Claude (팀장)
- 머리: **다크브라운 긴 웨이브 머리**, 앞머리 없이 옆가르마로 얼굴 옆으로 흘러내림, 뒷머리는 허리 근처까지 등을 덮는다. 웨이브는 끝으로 갈수록 굵게.
- 얼굴: 큰 갈색 눈, 가는 눈썹, 옅은 미소, 볼에 연한 홍조.
- 상의: **아이보리(크림)색 셔츠**, 소매를 팔꿈치까지 걷어 올림, 셔츠 자락은 바지 안에.
- 하의: **베이지색 와이드 슬랙스**, 가는 검은 벨트.
- 소품: 회색 태블릿(또는 얇은 노트북)을 가슴 앞에 안고 다님. 손가락으로 가리키는 포즈(업무 배정 때).

## 2. 남자 캐릭터 → GPT (개발자)
- 머리: **짧은 검은 웨이브 머리**, 앞머리가 이마로 자연스럽게 내려옴, 귀는 드러남.
- 얼굴: **얇은 검은 테 안경(둥근 사각형)**, 부드러운 미소.
- 상의: **검은색 크루넥 스웨터(맨투맨)**, 소매 살짝 걷음. (후드 없음, 로고 없음)
- 하의: **차콜(짙은 회색) 슬랙스**.
- 신발: 흰 스니커즈에 검은 포인트.
- 소품: 은색 노트북을 옆구리에 끼거나 한 손으로 들고 다님. 서 있을 때 **한 손을 주머니에** 넣는 포즈.

## 3. 여자 캐릭터 2 → Gemini (분석가)
- 머리: **검은 머리를 높게 올린 똥머리(top bun)**, 양옆·앞으로 잔머리 몇 가닥. (안경·헤드폰 없음)
- 얼굴: 큰 눈, 또렷한 미소.
- 상의: **연한 파란색(라이트 블루) 버튼 셔츠**, 소매 걷음, 바지 안에.
- 하의: **검은색 와이드 슬랙스**.
- 소품: **흰 테이크아웃 커피컵(갈색 슬리브)** 을 한 손에, 회색 노트북을 다른 팔에 낌. 앉아서는 턱을 괴는 자세.

## 표정 5종 (얼굴 텍스처 교체)
| 표정 | 모습 | 쓰는 상황 |
|---|---|---|
| 기본 | 옅은 미소, 눈 뜸 | 대기·앉아 있음·걷기 |
| 웃음 | 눈을 감고 활짝 웃음 | 말풍선으로 말할 때, 업무 완료, 보고 |
| 놀람 | 눈 크게, 입 동그랗게 | 새 업무 접수, 오류, 접속 키 오류 |
| 집중 | 입 다물고 눈 약간 가늘게, 진지 | 타이핑·필기·스크롤 |
| 생각 | 눈 위를 보고, 손가락을 턱에 | 생각(think)·턱 괴기(chin)·계획 수립 |

## 포즈 매핑 (앱 상태 → 자세)
- stand(서 있음): 소품 들고 가볍게 무게 중심 이동, 가끔 두리번.
- walk(걷기): 팔 흔들기, 소품은 한 손 고정.
- sit/type(책상): 외장 키보드 타이핑, 집중 표정. 쉴 때는 다리 꼬기·턱 괴기·기지개·커피 한 모금.
- talk(회의): 웃음/기본 표정 번갈아, 손짓. Claude 는 태블릿을 보며 가리키기.
- write(화이트보드): 집중 표정, 한 팔 들어 필기.
- coffee(커피 코너): 컵 들고 한 모금, 기본/웃음.

## 이름표
흰색 알약형 배경 + 팀원 색 점(그림 캐릭터는 지금 표정의 얼굴) + 굵은 이름, 아래에 연회색 작은 알약형으로 역할(예: 팀장 / 개발자 / 분석가). 다크 테마 대응.
- 겹침 정리(app.js `declutter`, 매 프레임): 카메라에 가까운 팀원부터 자리를 잡고, 겹치는 뒤쪽 팀원(옆자리)의 이름표(이름+역할 알약)는 겹친 높이만큼 위로 밀어 올린다.
  말풍선은 가장 최근에 말한 팀원이 우선이고, 겹치는 이전 말풍선은 데스크톱에서는 그 위로 띄우고 휴대폰에서는 잠시 숨긴다.
- 출근 인사 말풍선은 유리문을 지나 현관 안(ENTRANCE)에 들어선 뒤에 띄운다(문 밖은 왼쪽 사이드바에 가까워 잘린다).
- 방 이름 칩(decor.js)은 이름표와 겹치면 칩 쪽을 숨긴다(이름표 우선).

## 새 착석·휴식 포즈 (2026-10-14)

- 원래 시트의 얼굴·헤어·복장을 기준으로 생성한 `docs/ref/characters-seated-work-v1.png`에서 정면·측면·후면 착석 이미지를 분리했다. 손은 외장 키보드 위치를 향하며 무릎 위 노트북을 제거했다. 착석 전체 높이 기준 1.46m, 책상 뒤 좌석 거리 0.95m를 사용한다. 빌보드의 시선은 실제 모니터 좌표를 향한다.
- 재생성: `python3 scripts/sprites/seat-work.py` (Pillow·numpy). `web/sprites/*-work.png`, `work-seated.js`는 생성물이며 직접 수정하지 않는다.
- `docs/ref/characters-office-life-v1.png`는 소파 착석·차 마시기·서서 발표하는 별도 포즈다. `python3 scripts/sprites/office-life.py`로 `*-life.png`, `office-life.js`를 재생성한다. 현재 이 포즈는 한 방향 그림을 좌우 반전하며 모든 각도의 실제 입체를 제공하지 않는다.
- `web/office-life.js`: 대기 중 산책·탕비실 차·소파 휴식·창가 차·2인 담소를 순환한다. 업무가 시작되거나 화면이 숨겨지거나 동작 줄이기가 켜지면 취소한다. 실제 계획 회의에서는 팀장이 서서 PT하고 다른 팀원은 앉는다. 휴식 대사는 연출이며 모델이 생성한 업무 결과가 아니다.
- 사람·이름표·활동 카드를 클릭하면 인사 말풍선과 개인 대화창이 열린다. 현재 상태/역할은 즉시 응답하며 자유 질문은 `/api/ask`로 선택한 팀원에 전달한다. 모의 실행은 모의 응답을 명시한다. 대화 이력은 브라우저 메모리에만 남는다.
- `character-quality-target.png`는 목표 품질 참고다. 현재 캐릭터는 2.5D 이미지이며 목표 품질의 스킨/리깅된 실시간 3D 캐릭터 제작은 완료되지 않았다.

## 팀원별 사람 이미지 선택 (2026-10-15)

에이전트 화면에서 **팀원의 사람 이미지를 클릭해 열리는 선택 모달**에서 모두 한국인으로 구성된 기존 Claude·GPT·Gemini와 신규 7명(하나 24세, 준 27세, 소라 31세, 민 29세, 도윤 34세, 지유 26세, 현우 38세), 40대 한국 남성 3명(서진 43세·태호 48세·성우 45세)을 더해 총 13종을 고른다. 모델·역할·업무 상태와 외형은 독립적이다. 선택은 브라우저 localStorage에 팀원 이름별로 저장되며 다른 기기에는 공유되지 않는다. 저장소가 차단되면 현재 탭에서만 유지된다.

- 원본: `docs/ref/people/<id>.png`, 인물마다 독립된 4열×5행 투명 시트. built-in image_gen으로 생성했으며 전체 프롬프트와 인물별 외형 명세는 `scripts/sprites/people-prompts.json`에 보관한다.
- 생성: `python3 scripts/sprites/people.py` (Pillow·numpy 필요). 원본 알파를 유지해 행 사이의 빈 공간을 찾아 분리한다.
- 결과: `web/sprites/people/<id>.png`(서기 4방향·걷기 3방향·앉기 3방향·일어나기), `<id>-work.png`(타이핑 3방향), `<id>-life.png`(소파·차·발표), `<id>-faces.png`(6표정). `web/sprites/people.js`는 기존 세 좌표표에 신규 인물 10명을 병합하는 생성물이다. 생성물은 직접 수정하지 않는다.
- 런타임: `web/character-looks.js`가 선택값 검증·저장을 맡는다. `app.js`는 선택한 외형 ID로 rig와 얼굴 아바타를 생성하고, 선택 즉시 위치·방향·업무를 유지하며 rig를 교체한다. `dashboard.js`도 외형 변경을 반영한다.
- 기존 캐릭터와 동일한 2.5D 방식이다. 걷기는 서기/걷기 프레임을 번갈아 표시하며 휴식 포즈는 한 방향을 반전해 사용한다.

성우는 흰색 정장 와이셔츠·차콜 정장 바지·안경·검정 구두를 착용한다.

- 인물은 현재 팀에서 중복 선택할 수 없다. 다른 팀원이 사용 중인 이미지는 모달에서 비활성화한다. 이전에 중복 저장된 선택값은 팀을 구성할 때 남은 인물로 정리한다. 이름을 클릭하면 기존 개인 대화가 열린다.

## 신규 인물 휴식 포즈 보완 (2026-10-15)

신규 인물의 일부 차·발표 이미지가 허벅지나 발목에서 잘리고, 휴식 이미지에 포함된 별도 의자가 실제 소파와 겹치는 문제를 확인했다. 기존 `characters-office-life-v1.png`의 자세를 참고해 신규 10명 각각의 전용 시트 `docs/ref/people-life/<id>.png`를 생성한다.

- 3열×2행: 가구 없는 소파 착석 정면·오른쪽 측면·후면, 전신 차 마시기, 전신 발표, 앉아서 차 마시기. 얼굴·헤어·복장은 기존 인물별 시트로 고정한다.
- 전체 프롬프트: `scripts/sprites/people-life-prompts.json` (built-in image_gen).
- `people.py`가 휴식 전용 시트를 우선 사용하고, 기존 업무·걷기·표정 이미지는 유지한다. 분리할 때 옆 칸에서 넘어온 신발·머리 조각을 연결 영역으로 제외한다.
- 런타임은 소파 착석의 세 방향을 고르고, 별도 의자를 이미지에 넣지 않아 실제 소파·탕비실 의자 위에 그대로 앉는다. 앉아서 차 마시기는 `seatedTea`로 구분한다. 기존 3명은 기존 휴식 에셋을 유지하며 추가 포즈가 없으면 기존 착석으로 대응한다.

실제 소파 위에서는 몸통을 좌판에 유지한 채 무릎 아래의 릴리프 깊이를 앞쪽으로 내밀어 쿠션에 다리가 잘리지 않게 한다. 확대 시 인물을 가리는 블라인드는 흐리게 표시한다. 신규 60포즈의 방향 전환·높이와 모의 업무 완료를 브라우저에서 확인했으며, 이미지 검수표는 `docs/ref/people-life-qa-1.jpg`, `people-life-qa-2.jpg`에 저장했다.

## 걷기 방향 검수 (2026-10-15)

전체 13종의 서기·걷기 측면 이미지를 비교했다. 신규 인물 중 준·소라·민·지유·서진은 원본의 서기 좌/우 칸이 요청 순서와 반대여서, 걷기/서기 교대 시 몸이 반대 방향으로 뒤집혔다. `scripts/sprites/people.py`의 `REVERSED_STANDING`에서 해당 5종의 서기 프레임을 바로잡아 아틀라스와 좌표표를 함께 생성한다. 나머지 8종의 방향은 기존대로 유지한다. 생성된 파일을 직접 편집하지 않는다.

## 사무실 강아지 2마리 (2026-10-15)

웰시코기(청록색 목줄)와 비글(황갈색 목줄)은 에이전트와 별개로 사무실을 산책하는 반려견이다. 팀 설정·업무 배정·API 호출에 참여하지 않는다. 이름표를 누르면 말풍선으로 반응하며, 가끔 준비된 한국어 혼잣말을 한다.

- 제작: built-in `image_gen`, 품종별 독립된 투명 배경 4열×3행 시트. 원본은 `docs/ref/dogs/corgi.png`, `beagle.png`, 전체 프롬프트는 `scripts/sprites/dog-prompts.json`에 보관한다.
- 재생성: `python scripts/sprites/dogs.py` (Pillow·numpy). 칸을 넘은 코·꼬리를 보존하도록 연결된 전신 영역을 추출한다. 생성물 `web/sprites/dogs/*.png`, `dogs.js`를 직접 수정하지 않는다.
- 각 12자세: 측면 서기 2방향, 정면·후면 서기, 측면·정면·후면 걷기 각각 2프레임, 앉기, 냄새 맡기. 왼쪽 걷기는 오른쪽 걷기 이미지를 반전한다. 동일 방향의 걷기 배율을 고정해 프레임 교대 시 크기가 튀지 않도록 한다.
- 사무실 강아지(`office-dogs.js`)는 공간 테마 공통화(docs/space-themes.md)로 지웠다. 사무실 산책 손님은 공통 조연 엔진(`web/life.js`)의 방문객 3명(사람 그림)이다. 강아지 그림 자료(`web/sprites/dogs/`)는 남아 있지만 쓰지 않는다.
