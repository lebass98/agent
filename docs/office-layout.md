# 실제 사무실 배치 (2026-10-15)

사진 기반 미리보기의 구조를 실제 사무실(`/`)에 적용했다. 미리보기의 간단한 책상 모델을 가져오지 않고, 기존 `legacyDeskSet`·AppleAssets·의자·소파·탕비 가구·책장·그림·캐릭터 제작기를 재사용한다. 기존 가구는 크기를 유지하고 구역별 이동과 방향 회전만 한다.

- 전체 평면: 40×40 월드 단위. 실측 도면이 아닌 넓은 재구성이다.
- 업무 좌석(2026-10-17 공간 테마 공통화, docs/space-themes.md): 작업석 12. 0번은 팀장실의 팀장 책상, 1~11번은 업무 공간에서 가로 3석의 한 줄과 맞은편 한 줄이 마주 보는 묶음 2개(뒤쪽 줄 오른쪽 1석은 비움). 예전 앞쪽 두 줄(6석)은 없앴다. 서버 팀원만 실제 사람으로 표시하고 나머지는 빈 책상이다.
- 탕비실: 왼쪽 앞 모서리, 출입문은 오른쪽 벽. 냉장고·커피 머신·선반·타원 테이블은 기존 구성 그대로 이동했다.
- 회의실 1·팀장실: 오른쪽 유리 복도. 회의실 1은 긴 테이블·의자 12·TV(발표 자리 `PRESENT_SPOT` = TV 옆). 예전 '회의실 2'(`rooms.exec`)는 동물원 팀장 전망대와 같은 역할의 **팀장실**로 바꿨다: 팀장 책상·손님 의자 2·본부장 소파(조연 자리)·책장. 검수 보고 자리(`REPORT_SPOT`)도 팀장 책상 옆이다.
- 베란다: 창가 너머에 바닥·난간·출입문을 연결한다. 라운지는 오른쪽 앞에 기존 소파와 기기를 유지한다.
- 밤 조명: 기존 가구 재질의 낮/밤 보간, 따뜻한 램프와 탕비·회의실 조명, 파란 유리 프레임·베란다 LED, 창밖 야경을 적용한다. 라이트 화면에서는 실제 해의 고도를 따르고, 다크 화면에서는 시간과 관계없이 밤 조명·야경을 우선 적용한다. 화면 테마 모드를 고르면 라이트 화면도 항상 낮 조명이 된다.

`Decor.spots`·`navRects`·`LIFE`·`NPC`가 좌석, 이동 장애물, 휴식 장소, 조연 장소를 함께 정의한다(공통 규격 `ThemeKit.check`). 마주 보는 책상은 기존 책상 세트를 통째로 회전하고 모니터 목표점·앉는 위치·의자 숨김 좌표도 같은 변환을 사용한다.

검증: `node tests/office-layout.cjs`, `node tests/office-life.cjs`, 브라우저에서 낮/밤·회의실 시점·모의 업무 완료를 확인했다.
