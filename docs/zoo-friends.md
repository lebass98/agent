# 동물원 친구 3종

사용자가 제공한 참고 이미지의 우사기·치이카와·하치와레를 Three.js 메시로 재구성했다. 이미지 빌보드가 아닌 입체이며, 정면 외 측면·뒷면과 귀·팔·다리·꼬리 관절이 있다.

- `web/zoo-friends.js`: 모델 생성·표정·걷기 애니메이션, ZooAnimals에 3종 등록. 기존 12종과 합쳐 선택 목록 15종.
- `web/zoo-friends-life.js`: 동물원에 손님 3마리를 생성. 기존 길 찾기의 안전한 경로만 사용하며 팀원 데이터에는 넣지 않는다. 배경 탭·움직임 줄이기에서는 정지.
- 에이전트 → 팀원 얼굴 → 우사기/치이카와/하치와레로 즉시 교체. 브라우저에 저장하며 기존의 팀원 간 중복 선택 제한을 따른다. 산책 손님과 에이전트는 별개다.
- `previews/zoo-friends.html`: 회전·확대·걷기/쉬기·산책을 확인하는 독립 3D 미리보기. 프로젝트 루트에서 정적 서버로 열기.
- `node tests/zoo-friends.cjs`: 입체 범위·관절·선택 등록·49개 산책 경로·세 마리 이동·배경 정지 검증.

모델은 코드로 만드는 스타일화된 1차 에셋이다. 원본 일러스트의 손그림 외곽선·의상·바구니는 포함하지 않는다.
